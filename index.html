ModelID / 浏览器模型识别工具基于 ModelTrace

开始一次模型识别

ModelID 比较模型自行选择数字时表现出的偏好。它能帮助你判断回答更接近哪个已收录模型，但无法独立证明接口实际使用的模型。

  1. 复制题目。在“手动粘贴”中，分别复制三条题目。
  2. 向同一个模型提问。每题使用独立对话，不让模型调用代码、计算器或其他随机数工具。
  3. 粘贴完整回答并识别。保留原始格式，不排序、不去重，也不补齐缺失数字。

计算在你的浏览器中完成，粘贴的回答不会发送到服务器；本页面不要求提供 API Key。

尚未收录的模型也会得到候选排名。GPT‑6.1 Codex 指纹与 gpt-6-astra 仍有混淆，请结合其他证据判断。
